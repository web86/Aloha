# Codex instructions

- Follow KISS. Prefer the simplest implementation that meets the requirements.
- Preserve work in progress. Inspect the current changes before editing and avoid overwriting or discarding existing work.
- After completing and verifying each stage, commit and push its changes to the working feature branch.
- Keep credentials, tokens, private data, local environment files, backups and logs out of Git.
- Start the next stage only after the user agrees.
